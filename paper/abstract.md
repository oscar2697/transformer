# Abstract

The Transformer architecture (Vaswani et al., 2017) has become the backbone of modern natural language processing, yet most open-source implementations rely on high-level PyTorch modules that abstract away the underlying mathematical machinery. We present a complete, from-scratch PyTorch implementation of the Transformer that reproduces every component—MultiHeadAttention, PositionwiseFeedForward, and Positional Encoding—using only primitive tensor operations, without `nn.MultiheadAttention`, `nn.Transformer`, or `torchtext`.

Our implementation is validated empirically on the **Tatoeba English → German** sentence-pair collection (CC-BY release via https://www.manythings.org/anki/; ~330k pairs). With a compact configuration (`d_model = 256`, 4 encoder and 4 decoder layers, 8 heads, `d_ff = 1024`, label smoothing $\epsilon = 0.1$, batch size 32, warmup 2000 steps, ~12 M parameters), trained for 8 epochs on a single Google Colab GPU in ≈ 56 minutes, the model reaches corpus-level BLEU = 0.38 and chrF2 = 11.28 on the test set (n = 3,296) at validation perplexity 149.84. These numbers are characteristic of a deliberately short training budget; the validation loss curve is still decreasing at the end of the run (Section 5.2) and the implementation itself passes all 17 unit tests, confirming that the architecture is correct but under-trained.

We further provide a self-contained data pipeline with regex-based tokenization, a built-from-scratch vocabulary, and length-bucketed batching. A suite of 17 unit tests serves as a formal correctness contract for every architectural component. Because attention weights are exposed as first-class outputs of the forward pass, the implementation also supports interpretability analysis: we report per-sentence heatmaps of encoder self-attention, decoder self-attention, and decoder cross-attention on the final layer (Section 5.5).

Planned future experiments include subword tokenization with SentencePiece, a comparative baseline against PyTorch's native `nn.Transformer`, beam search decoding, and a comprehensive ablation study covering label smoothing, warmup schedules, pre-LN versus post-LN architectures, and per-head attention analysis. All code, hyperparameters, and experimental logs are publicly available, designed for transparency, auditability, and pedagogical use.
